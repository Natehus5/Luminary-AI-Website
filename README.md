# Luminary AI Website Starter

This is a simple, professional one-page website for **Luminary AI**.

It is built with plain HTML, CSS, and JavaScript, so you can open it in Cursor and edit it without installing Node, React, or any build tools.

## Files

```text
index.html
styles.css
script.js
assets/
  luminary-logo-clean.svg
  luminary-logo.png
  luminary-logo-from-signature.png
  luminary-mark.svg
  favicon.png
```

## How to use it in your GitHub repository

1. Unzip this folder.
2. Move the files into your existing GitHub repository folder.
3. Open the repository folder in Cursor.
4. Preview the site by opening `index.html` in your browser.
5. Edit the copy, services, and contact details in `index.html`.

## Suggested Git commands

From inside the repository folder:

```bash
git add .
git commit -m "Add Luminary AI starter website"
git push
```

## Hosting options

### Option 1: GitHub Pages

Good for a simple first launch.

1. Push these files to your GitHub repository.
2. In GitHub, go to the repository settings.
3. Open **Pages**.
4. Choose the branch that contains `index.html`, usually `main`.
5. Save the setting and wait for GitHub to publish the site.

### Option 2: Vercel or Netlify

Good if you want a custom domain, easy previews, and room to grow into a React or Next.js site later.

## Logo note

The file `assets/luminary-logo-from-signature.png` is cropped from your email signature screenshot.

The file `assets/luminary-logo-clean.svg` is a cleaner editable SVG version based on the same logo style and colors. The website currently uses the SVG because it stays sharp on all screen sizes.

If you have the original logo file from Canva, Adobe, Figma, or another design tool, replace the files in `assets/` with the original high-resolution SVG or PNG.
